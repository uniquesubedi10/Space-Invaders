# 🚀 Space Invaders (Pygame)

A classic **Space Invaders-style game** built using Python and the Pygame library. Control your spaceship, shoot enemies, and try to achieve the highest score before they reach you!

---

## 🎮 Features

* 👾 Multiple enemies with random spawn positions
* 🔫 Shooting mechanics with sound effects
* 💥 Collision detection system
* 🎵 Background music and explosion effects
* 🧮 Real-time score tracking
* ☠️ Game Over screen

---

## 🖼️ Game Preview

* Player spaceship moves left/right
* Enemies descend gradually
* Bullet fires upward to destroy enemies

---

## 🛠️ Tech Stack

* **Python 3**
* **Pygame**

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/Space-Invaders.git
cd Space-Invaders
```

2. Install dependencies:

```
pip install pygame
```

3. Run the game:

```
python main.py
```

---

## 🎯 Controls

* ⬅️ / A → Move Left
* ➡️ / D → Move Right
* SPACE → Shoot

---

## 🚧 Known Issues

* Bullet state uses `is` instead of `==` (can cause bugs in some cases)
* Window resizing is enabled but not fully handled
